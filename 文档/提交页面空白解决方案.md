# 提交页面空白 · 解决方案

## 症状

进入题目提交页面(`/org/{orgId}/problem/{problemId}/submit`)后页面空白,没有任何提交方式可选。

## 根因

AOI 前端 `ProblemSubmit.vue` 的三种提交方式全部通过 `v-if` 控制:

```vue
<VTab v-if="problem.config.submit.form" value="form">可视化提交</VTab>
<VTab v-if="problem.config.submit.upload" value="upload-file">上传文件</VTab>
<VTab v-if="problem.config.submit.zipFolder" value="upload-dir">上传目录</VTab>
```

若 `problem.config.submit` 中 `form`、`upload`、`zipFolder` 三个字段**全部为 undefined/false**,则三个 `v-if` 同时不渲染 → 提交区域完全空白。

**更深层的原因:** API `GET /api/problem/{problemId}` 返回的 `config` 不是来自 problem 文档根,而是来自 `problem.data[]` 数组中匹配 `currentDataHash` 的那个条目:

```ts
// apps/server/src/routes/problem/scoped.ts:77
config: ctx._problem.data.find(({ hash }) => hash === ctx._problem.currentDataHash)?.config
```

MongoDB 中的数据模型:

```json
{
  "_id": "...",
  "currentDataHash": "5fcca66a...",
  "data": [
    {
      "hash": "45c9f611...",
      "config": { "label": "...", "submit": {}, ... }
    },
    {
      "hash": "5fcca66a...",  ← 当前版本
      "config": { "label": "...", "submit": { "language": "python" }, ... }
    }
  ]
}
```

**直接写 `config` 到 document 根无效**——API 读的是 `data[]` 里的。

## 诊断

### 1. 确认 MongoDB 中的 config

```bash
docker exec aoi-mongo-1 mongosh --quiet aoi --eval '
db.problems.findOne(
  { _id: UUID("问题ID") },
  { currentDataHash: 1, "data.hash": 1, "data.config": 1 }
)
'
```

### 2. 确认 API 返回

浏览器 F12 → Network → 刷新页面 → 找到 `problem/{id}` 请求 → 查看 Response 中的 `config.submit` 字段。

### 3. 常见坏配置

| 问题 | MongoDB 中的现象 | 效果 |
|---|---|---|
| config 写错位置 | `problem.config` 存在但 `problem.data[].config` 不存在 | API 返回 config 为 null,Submit tab 不显示 |
| submit 字段错误 | `submit: { language: "python" }` | 三个 v-if 全 false,无提交方式 |
| label 未设置 | `label: ""` 或 `label: "label"` | 提交页面显示但无法匹配 runner |

## 修复

更新 `data[]` 中**当前版本**(hash 匹配 `currentDataHash`)的 `config`:

```js
db.problems.updateOne(
  {
    _id: UUID("问题ID"),
    "data.hash": "当前currentDataHash的值"
  },
  {
    $set: {
      "data.$.config": {
        label: "uoj",                          // 匹配 azukiiro runner 的 labels
        solution: {},
        judge: { adapter: "uoj", config: {} }, // 评测适配器
        submit: {
          upload: true,                         // 上传文件提交
          zipFolder: true,                      // 上传目录提交
          form: {                               // 可视化在线 IDE 提交
            files: [
              {
                path: "main.cpp",
                label: "Main Code",
                type: { editor: { language: "cpp" } }
              }
            ]
          }
        },
        instanceLabel: "uoj"                   // 允许创建 Instance
      }
    }
  }
)
```

## `submit` 字段完整参考

### 上传文件

```json
"submit": { "upload": true }
```

显示"上传文件"标签页,用户选择一个或多个文件直接上传。

### 上传目录

```json
"submit": { "zipFolder": true }
```

显示"上传目录"标签页,用户选择本地文件夹,浏览器自动压缩为 zip 后上传。

### 可视化提交(在线 IDE)

```json
"submit": {
  "form": {
    "files": [
      {
        "path": "main.cpp",              // 文件在 zip 包中的路径
        "label": "Main Code",            // 编辑器标签
        "description": "Main solution",  // 可选:说明
        "default": "// your code here",  // 可选:默认代码
        "type": {
          "editor": { "language": "cpp" }  // 语法高亮: cpp/c/python/java/pas
        }
      }
    ]
  }
}
```

支持多文件:

```json
"form": {
  "files": [
    { "path": "main.cpp", "label": "Main", "type": { "editor": { "language": "cpp" } } },
    { "path": "header.h", "label": "Header", "type": { "editor": { "language": "cpp" } } }
  ]
}
```

### 三种方式可同时开启

```json
"submit": {
  "upload": true,
  "zipFolder": true,
  "form": { "files": [...] }
}
```

前端会显示三个标签页,用户任选其一。

## 关键教训

- **config 写在 `data[].config`,不是 document 根** — API 按 hash 匹配当前数据版本
- **`submit` 的 `upload`/`zipFolder`/`form` 至少开一个** — 否则提交页面空白
- **`label` 要匹配 runner** — 否则 solution 永不被领取
- **每次重新上传数据会生成新 hash** — 需要更新对应新 hash 的 data 条目
